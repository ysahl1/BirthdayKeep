
# Birthday Marker

Birthday Marker ist eine **lokale** und **datenschutzfreundliche** App zum Verwalten von Geburtstagen.  
Keine Accounts, kein Tracking, keine Cloud – alle Daten bleiben auf deinem Gerät.

***

## Features

- Geburtstage hinzufügen, bearbeiten und löschen  
- Anzeige von Alter, nächstem Geburtstag und verbleibenden Tagen  
- Konfigurierbare Benachrichtigungen (z.B. X Tage vorher, Uhrzeit)  
- Hell-/Dunkelmodus (und optional System-Theme)  
- Suche und Sortierung nach Name, Datum oder nächstem Geburtstag  
- Optionaler Import/Export der Daten (z.B. JSON/CSV)

***

## Datenschutz

- Alle Geburtstage werden **ausschließlich lokal** auf dem Gerät gespeichert.  
- Es gibt **keine** externe Server-Kommunikation, kein Tracking und keine Analysen.  
- Falls Kontakte-Zugriff angeboten wird: Es werden nur Name und Geburtstag gelesen; die Daten verlassen das Gerät nicht.  
- Exportierte Dateien können sensible Daten enthalten – der Umgang damit liegt vollständig beim Nutzer.

## Bedienung

1. App öffnen und über „+“ einen neuen Geburtstag anlegen.  
2. Name, Datum (und optional Notizen) eingeben.  
3. Über das Einstellungen-Icon können Benachrichtigungen (Zeit, Vorlauf), Theme und Anzeigeoptionen angepasst werden.  
4. Langdruck oder Icon in der Liste zum Bearbeiten/Löschen eines Eintrags.
